# Brooklyn Bowl Kiosk

PWA-терминал самообслуживания, реализованный как SPA на Vanilla TypeScript и Vite. Меню строится из корневого `menu.json`; карточки, категории, поиск и связанные блюда не содержат вручную заданных позиций.

## Возможности

- Welcome-экран, выбор формата заказа, меню, модальное блюдо, ваш заказ, подтверждение и статус приготовления.
- Поиск, категории, избранное, соусы, добавки, рекомендации, Local Storage и автоматический возврат на Welcome через 60 секунд бездействия.
- PWA manifest, service worker, touch-first интерфейс и service FAB для вызова официанта.
- Русский и английский интерфейс, защищённый служебный вход и автоматическая очистка гостевой сессии.
- Модульные страницы, компоненты, store, router и сервисы, готовые к замене mock-слоя на REST/WebSocket API.

## Локальный запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Служебная панель открывается после шести быстрых нажатий на логотип на Welcome-экране. Пароль задаётся только в серверной переменной `ADMIN_PASSWORD_HASH`.

Команда `npm run sync:images` использует системную утилиту `cwebp`: исходные фотографии скачиваются, уменьшаются до 1200 px и сохраняются в WebP.

На текущей машине для проверки используется изолированная Node.js в `.tools/`; она исключена из Git. При наличии системного Node команды работают без дополнительной настройки.

## Структура

`src/pages` содержит экраны, `src/components` — переиспользуемые UI-компоненты, `src/store` — состояние заказа, `src/services` — слой данных и будущих интеграций, `src/router` — маршрутизацию. Палитра бренда находится в `src/config/brand.json`.

## Android

После публикации PWA следующим шагом добавляется Capacitor и Android-проект. Это потребует Android SDK / Android Studio, но не изменит SPA-архитектуру.
